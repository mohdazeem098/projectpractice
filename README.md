# Project Practice

This repository is a front-end practice project built with React, TypeScript, Vite, Tailwind CSS, and shadcn-ui.

It contains a small app scaffold and UI components for learning and experimenting with modern frontend development.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn-ui
- Supabase

## Getting Started

1. Open the app folder:

```bash
cd gen-my-backend-main
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open the local URL shown in the terminal to view the app in your browser.

## Build for Production

```bash
npm run build
```
